# Retrospektivní aplikace

Webová aplikace pro kolaborativní vedení agilních sprintových retrospektiv v reálném čase.

## 🚀 Rychlý start

1. **Lokální testování**: [SETUP.md](./SETUP.md) — Jak nastavit aplikaci na svém počítači
2. **Nasazení**: [DEPLOYMENT.md](./DEPLOYMENT.md) — Jak deployovat na Vercel

## Dokumentace

- [SPEC.md](SPEC.md) — Detailní funkční zadání
- [ARCHITECTURE.md](ARCHITECTURE.md) — Technická architektura a datový model
- [.github/copilot-instructions.md](.github/copilot-instructions.md) — Instrukce pro GitHub Copilot

## Technologie

- React + Vite + TypeScript
- Tailwind CSS
- Supabase (Postgres + Realtime)
- Vercel (hosting)

## Funkce

✅ Kolaborativní vedení retrospektiv v reálném čase  
✅ Dot-voting (3 hlasy na osobu na kategorii)  
✅ Slučování duplicitních bodů  
✅ Realtime synchronizace pro všechny účastníky  
✅ Bez přihlašování (jen jméno + random ID)  
✅ Historizace akcí mezi retrospektivami
